# 本地简历编辑器

纯 HTML、CSS、JavaScript 的离线简历编辑器。无需安装依赖、账号或服务器。

## 打开与编辑

双击 `index.html`，建议使用最新版 Chrome 或 Edge。首次打开会显示随附的示例简历；点击“新建空白”可从空白开始。点击姓名、求职方向、联系方式、模块标题及正文即可直接修改。要点中按 Enter 新增下一条，清空要点后按 Backspace 可删除空条；也可以一次粘贴多行纯文本，自动拆成多条要点。

“模块管理”可开关与排序一级模块。项目、工作、教育、自定义条目以及技能组可独立开关和排序。桌面可拖动手柄；手机可使用 ↑ ↓。编辑态的隐藏条目仍可修改，预览及打印时不显示。

照片区在编辑态点击即可选择本地图片；“显示照片”复选框可关闭照片。图片会缩放后保存在简历 JSON 中。

## 保存、导入与导出

修改会在短暂延迟后自动保存到当前浏览器的 LocalStorage（键 `localResumeBuilder.current.v1`）。刷新或下次打开同一文件时自动恢复。浏览器清除站点数据、使用不同浏览器或移动 `index.html` 路径后，本地保存可能无法沿用，因此建议定期点击“导出 JSON”备份。

“导入 JSON”可恢复先前导出的 `.resume.json` 文件。导入前会检查版本与基本数据结构；无效文件不会覆盖当前简历。首次示例数据来自 `default-resume.js`。“重置示例”需要两次确认，会以示例替换当前内容。

## 导出 PDF

点击“导出 PDF”，在浏览器打印对话框中选择“另存为 PDF”。页面按 A4 排版，允许自然分页；正文仍是可选择、可搜索的文字。浏览器会尝试以“姓名_求职方向_日期”作为建议文件名。打印预览中若浏览器默认开启页眉页脚，可在打印设置中关闭。

手机可查看、少量修改、开关项目及启动打印；实际 PDF 保存选项由手机浏览器和系统提供。
