# 产品规格：Local Resume Builder v1

## 1. 产品定位

一个本地优先、无需账号、无需服务器的简历编辑器。

它不是“在线简历网站”，也不是“模板商城”。
它解决的核心问题只有一个：

> 简历内容和排版分离。以后用户只修改内容，系统自动负责视觉和分页。

## 2. 使用场景

### 主用户
- 经常修改项目经历、工作经历、技能
- 针对不同岗位选择不同项目
- 不想每次在 Word 里重新调行距、字号、分页
- 需要快速导出 PDF

### 其他用户
- 拿到这个工具后可从空白简历开始
- 能把自己原有简历的文字复制粘贴进去
- 不要求 v1 自动识别/解析 Word、PDF

## 3. 页面模式

### 编辑模式
显示：
- 顶部工具栏
- 模块开关
- 新增/删除按钮
- 拖拽手柄
- 项目开关
- 可编辑文字

### 预览模式
只显示简历本身。
视觉尽量接近最终 PDF。

### 打印模式
只显示最终简历。
所有编辑 UI 隐藏。

## 4. 顶部工具栏

建议按钮：
- 编辑 / 预览
- 新建空白
- 导入 JSON
- 导出 JSON
- 导出 PDF

可选：
- 恢复上次自动保存
- 展开“模块管理”

工具栏不参与打印。

## 5. 基本信息

字段建议：
- name
- headline
- phone
- email
- location
- photo
- photoEnabled

注意：
- 不要求 GitHub / 项目链接作为正式一等字段
- 联系方式排版保持简单
- 照片靠右，避免抢占过多正文宽度

## 6. 一级模块

预置：
1. 个人概述
2. 教育背景
3. 项目经历
4. 工作经历
5. 专业技能
6. 自定义模块

所有 section 至少有：
- id
- type
- title
- enabled
- order
- items / content

一级 section 可拖动排序和隐藏。

## 7. 项目经历

这是最重要的模块之一。

每个项目必须：
- 独立 enabled
- 独立排序
- 可新增
- 可删除
- 直接编辑

建议字段：
- title
- subtitle / summary（可选）
- date（可选）
- techStack（可选）
- bullets[]

bullet：
- 可直接编辑
- 支持 Enter 新建 bullet
- 支持删除空 bullet
- 支持一次粘贴多行

不同岗位可只开启部分项目，例如只显示项目 3、4，不显示 1、2。

## 8. 工作与教育

沿用 item 模型。

建议字段：
- title
- organization
- date
- subtitle
- bullets[]

不要强制每个字段都存在。
没有的字段不占空间。

## 9. 技能

v1 可以使用分组：
- label：如“Agent / RAG”
- content：一段技能列表

支持多组技能。
技能组可排序、开关。

## 10. 自定义模块

为了能给其他人使用，需要允许：
- 新增自定义 section
- 修改 section 标题
- 添加多个 item
- 每个 item 有 title / subtitle / date / bullets

不需要自由布局系统。

## 11. 数据策略

### Source of truth
JSON。

### LocalStorage
每次内容变化后 debounce 自动保存。

建议 key：
`localResumeBuilder.current.v1`

### JSON 导出
下载一个 `.resume.json` 文件。

### JSON 导入
读取并校验：
- schemaVersion
- 基本字段
- sections

无效 JSON 要给友好错误提示，不破坏当前数据。

### HTML
不是数据源。
不要实现“导出 HTML 作为主要备份”。

原因：
- HTML 混合了内容和样式
- 后续模板升级困难
- section/item 开关与排序信息不易可靠恢复
- JSON 更适合作为长期数据格式

## 12. 视觉与排版

目标参考：`reference_resume_shengyuliu.pdf`

特点：
- 高信息密度但不拥挤
- 清晰 section 层级
- 不做视觉装饰
- 重点依赖字体、字号、粗细、间距和细线
- 不使用卡片化布局

照片作为唯一明显偏离参考简历的元素。

## 13. 分页

A4。
建议：
- 页面左右边距 15~18mm
- 上下 14~18mm
- 正文字号约 9.5~11pt 范围内自行调优
- section 标题使用 `break-after: avoid`
- item 可尝试 `break-inside: avoid`
- 如果 item 很长，允许自然跨页，不要导致大片空白
- 不要求第一页塞满
- 不要求总页数为 1

## 14. 响应式

桌面宽屏：
- 页面中央显示 A4 风格画布
- 编辑控件尽量贴边，不干扰简历

手机：
- 不强制真实 A4 缩放到很小
- 阅读宽度适配手机
- 打印时仍按 A4
- 工具栏可折叠
- 拖动排序不可靠时显示 ↑ ↓

## 15. 不做的内容（v1）

- 不做账号系统
- 不做云同步
- 不做 AI 自动改写
- 不做 Word/PDF 智能解析
- 不做 ATS 评分
- 不做多套模板切换
- 不做 GitHub 字段体系
- 不做复杂富文本
- 不做所见即所得自由布局
- 不做服务端 PDF
