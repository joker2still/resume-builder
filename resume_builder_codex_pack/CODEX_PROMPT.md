# Codex 开发任务

请实现一个纯前端、本地优先、无需安装/无需后端的简历编辑器。

## 核心理念

内容与排版彻底分离。用户以后只维护简历内容，排版由模板负责。

不要：
- React / Vue / FastAPI / 数据库 / 登录
- 构建复杂 SaaS
- 把用户内容写死在 HTML 结构里
- 使用截图方式生成 PDF
- 为了“一页简历”去压缩字号或间距

可以：
- 原生 HTML + CSS + JavaScript
- LocalStorage
- 一个 vendored 的轻量排序库（若确实必要），但优先原生实现
- 浏览器 `window.print()` + print CSS 导出 PDF

## 必须完成

### 1. 编辑体验
- 页面本身就是最终简历预览。
- 有“编辑模式 / 预览模式”。
- 编辑模式下直接点击文字修改，尽量使用 contenteditable，而不是左侧复杂表单。
- 支持多行粘贴。
- 纯文本保存，避免把富文本 HTML 写进数据。
- 修改后自动保存到 LocalStorage。

### 2. 简历模块
至少内置：
- 基本信息：姓名、求职方向/Headline、手机、邮箱、所在地、照片
- 个人概述
- 教育背景
- 项目经历
- 工作经历
- 专业技能
- 自定义模块

每个一级模块：
- 可显示 / 隐藏
- 可拖动排序

项目经历里的每个项目：
- 独立显示 / 隐藏
- 独立拖动排序
- 可新增 / 删除

建议教育、工作经历、自定义模块中的 item 也沿用相同的数据结构，允许排序和开关。

### 3. 照片
- 保留照片区。
- 点击照片可替换本地图片。
- 图片存入浏览器本地数据（可用 data URL）。
- 打印 PDF 正常显示。
- 如果用户关闭照片，可隐藏且布局自动回流。

### 4. 数据
数据源必须是结构化 JSON，不要以 HTML 作为 source of truth。

支持：
- LocalStorage 自动保存
- 导出 `.json`
- 导入 `.json`
- 新建空白简历
- 重置当前简历（需要二次确认）

JSON 内应保存：
- schemaVersion
- 基本信息
- sections
- section 顺序
- section enabled
- item 顺序
- item enabled
- photo
- 可选 metadata

不要强求“智能解析别人的整份简历”。v1 只需保证：
- 新用户可以新建空白简历
- 直接在页面对应位置粘贴文本
- item 的 bullet 区域支持一次粘贴多行文字
- 添加新模块/新项目很方便

### 5. PDF
点击“导出 PDF”：
- 使用 `window.print()`
- `@page { size: A4; ... }`
- 打印时隐藏编辑工具栏、按钮、拖拽手柄、开关等
- 文本必须保持可选择/可搜索，不要生成截图 PDF
- 不强制一页；内容自然增长到 2 页、3 页
- 尽量避免标题孤立在页尾
- 尽量避免一个短 item 被分页拆开
- 但不要为避免分页而缩小字号

打印前可以临时设置 `document.title`，建议格式：
`姓名_求职方向_YYYYMMDD`
帮助浏览器保存 PDF 时生成更合理的默认文件名。

### 6. 桌面与手机
桌面：
- 完整编辑
- 拖动排序
- 开关
- 导入导出
- 打印

手机：
- 优先保证阅读
- 能点文字做小修改
- 能开关项目
- 能导出 PDF
- 不需要在手机上实现复杂拖动体验；如果触摸拖动不好用，可提供上移/下移作为 fallback

### 7. 视觉
主要参考 `refs/reference_resume_shengyuliu.pdf`：
- 白底
- 黑/深灰正文
- 简洁直接
- 标题层级清晰
- section 标题 + 细分割线
- 不使用花哨卡片、大色块、渐变、侧边栏
- 保留照片，放在顶部信息区右侧
- 中文简历可读性优先
- 整体可以带一点 Notion 式克制感，但不要刻意模仿 Notion

### 8. 代码组织
建议至少：
- `index.html`
- `styles.css`
- `app.js`
- `README.md`

如果需要拆分：
- `storage.js`
- `model.js`
- `print.css`

不要引入 npm 构建步骤。最终应能直接打开 `index.html` 使用。

## 完成后
1. 自测主要功能
2. 根据 `ACCEPTANCE_CHECKLIST.md` 逐项检查
3. README 写清楚：
   - 如何打开
   - 如何新建/编辑
   - JSON 导入导出
   - 如何打印 PDF
   - LocalStorage 的说明
   - 浏览器兼容建议（优先 Chrome / Edge）
4. 不要擅自扩大需求。
