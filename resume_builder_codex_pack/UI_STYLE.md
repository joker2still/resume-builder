# UI / Style Notes

## 参考关系

### 当前简历
`refs/current_resume_zhangwenxuan.pdf`

内容可作为数据示例，但视觉不必沿用现有 Word 模板。

### 主要视觉参考
`refs/reference_resume_shengyuliu.pdf`

重点学习：
- 顶部姓名 + 联系方式直接展开
- section 标题非常清楚
- 横向细线
- 黑白/深灰
- 几乎没有装饰
- 大量信息靠排版层级，而不是卡片
- 项目、经历、论文等自然连续排列
- 允许多页

## 本项目的差异

需要加入照片：
- 建议 26~32mm 左右的头像区域
- 位于顶部右侧
- 不做圆形强装饰
- 方形或轻微圆角即可
- 如果照片关闭，正文自动占满宽度

## 字体

优先系统字体，确保离线：
- 中文：`"Microsoft YaHei"`, `"PingFang SC"`, `"Noto Sans CJK SC"`, sans-serif
- 英文/数字：可以直接继承系统 sans-serif

不要要求用户安装字体。

## 编辑态

编辑态不要破坏简历观感。
建议：
- hover 时极轻边框/背景提示
- 拖动手柄放在页面边缘
- enabled 开关放在 section 左/右侧浮动区域
- 新增按钮低存在感
- 预览态全部隐藏

## 色彩

黑、深灰、浅灰即可。
不要大面积主题色。
