# Acceptance Checklist

Codex 完成后必须逐项自检。

## 启动
- [ ] 不需要 npm install
- [ ] 不需要 Python/Node server
- [ ] 双击 `index.html` 可打开
- [ ] Chrome/Edge 正常

## 编辑
- [ ] 可切换编辑/预览
- [ ] 可直接点击姓名修改
- [ ] 可直接点击摘要修改
- [ ] 可直接修改项目文字
- [ ] 多行粘贴不会产生混乱富文本
- [ ] 修改后自动保存

## 模块
- [ ] 一级模块可开关
- [ ] 一级模块可排序
- [ ] 项目可单独开关
- [ ] 项目可排序
- [ ] 项目可新增
- [ ] 项目可删除
- [ ] 自定义模块可新增

## 数据
- [ ] LocalStorage 生效
- [ ] 导出 JSON
- [ ] 导入 JSON
- [ ] 导入失败不会覆盖当前简历
- [ ] 新建空白简历
- [ ] JSON 含 schemaVersion

## 照片
- [ ] 点击可更换照片
- [ ] 可关闭照片
- [ ] 照片导出 JSON 后可恢复
- [ ] 打印时正常显示

## PDF
- [ ] 使用 print，不是截图
- [ ] PDF 中文本可选择
- [ ] A4
- [ ] 允许 2+ 页
- [ ] 打印时不显示按钮/拖拽手柄/开关
- [ ] section 标题尽量不孤立页尾
- [ ] 不因分页自动缩小字体
- [ ] 文件名尽量包含姓名和日期

## 手机
- [ ] 手机可正常阅读
- [ ] 手机可做基本文字修改
- [ ] 手机可开关项目
- [ ] 手机可触发导出 PDF
- [ ] 排序有触摸可用方案或 ↑ ↓ fallback

## 视觉
- [ ] 白底
- [ ] 简洁黑灰
- [ ] section 标题 + 细线
- [ ] 无卡片堆叠
- [ ] 无大色块
- [ ] 无渐变
- [ ] 顶部照片不喧宾夺主
